# 全栈工程师学习路线

全栈工程师不是“什么都会一点”就够了，而是需要能独立理解业务、设计方案、开发前后端功能、管理数据、上线部署，并能持续维护系统。学习时可以按下面几个方向逐步积累。

## 一、计算机基础

### 1. 数据结构与算法

- 数组、链表、栈、队列、哈希表
- 树、二叉树、堆、图
- 排序、查找、递归、回溯、贪心、动态规划
- 时间复杂度与空间复杂度分析
- 常见算法题解题思路

### 2. 计算机网络

- OSI 七层模型与 TCP/IP 模型
- HTTP、HTTPS、DNS、TCP、UDP
- 三次握手、四次挥手
- HTTP 状态码、请求方法、请求头与响应头
- Cookie、Session、Token、JWT
- 跨域、CORS、CSRF、XSS
- WebSocket、SSE

### 3. 操作系统基础

- 进程与线程
- 并发与锁
- 内存管理
- 文件系统
- I/O 模型
- Linux 常用命令

### 4. 编程语言基础

- 变量、数据类型、流程控制
- 函数、作用域、闭包
- 面向对象与函数式编程
- 异常处理
- 模块化
- 类型系统
- 常用设计模式

## 二、前端开发

### 1. HTML

- HTML 基础标签
- 语义化标签
- 表单与校验
- 多媒体标签
- SEO 基础
- 可访问性基础

### 2. CSS

- 选择器、盒模型、层叠与继承
- Flex 布局
- Grid 布局
- 定位、浮动、层级
- 响应式布局
- 动画与过渡
- CSS 预处理器，如 Sass、Less
- CSS 工程化方案，如 CSS Modules、Tailwind CSS

### 3. JavaScript

- 基础语法与数据类型
- 原型与原型链
- 作用域与闭包
- this 指向
- 事件循环
- Promise、async/await
- 模块化规范
- DOM 与 BOM
- ES6+ 常用特性

### 4. TypeScript

- 基础类型
- 接口与类型别名
- 泛型
- 联合类型与交叉类型
- 类型收窄
- 条件类型、映射类型、工具类型
- tsconfig 配置
- 类型声明文件

### 5. 前端框架

- Vue 或 React 至少熟练掌握一个
- 组件化开发
- 状态管理
- 路由
- Hooks 或 Composition API
- 服务端渲染 SSR
- 静态站点生成 SSG
- 常见性能优化

### 6. 前端工程化

- npm、pnpm、yarn
- Vite、Webpack、Rollup
- Babel、ESLint、Prettier
- 单元测试、组件测试、端到端测试
- 前端监控与错误上报
- 浏览器兼容性处理
- 打包体积优化

## 三、后端开发

### 1. 后端语言

建议至少深入掌握一门后端语言：

- Node.js
- Java
- Go
- Python

如果以前端转全栈为主，可以优先选择 Node.js；如果目标是企业级后端岗位，可以重点学习 Java 或 Go。

### 2. Node.js 后端

- Node.js 运行时机制
- CommonJS 与 ES Module
- 事件循环
- 文件系统、路径、流
- Express、Koa、NestJS
- 中间件机制
- 参数校验
- 错误处理
- 日志系统
- 定时任务

### 3. API 设计

- RESTful API
- GraphQL 基础
- 请求参数设计
- 响应结构设计
- 分页、筛选、排序
- 接口版本管理
- 接口鉴权
- 接口限流
- Swagger / OpenAPI 文档

### 4. 身份认证与权限

- 登录注册流程
- 密码加密与安全存储
- Session 认证
- JWT 认证
- OAuth 2.0 基础
- RBAC 权限模型
- 单点登录基础

### 5. 后端架构基础

- MVC 分层
- Controller、Service、Repository 分层
- DTO、VO、Entity
- 依赖注入
- 配置管理
- 异常统一处理
- 日志与链路追踪
- 单体应用与微服务基础

### 4. ORM 与数据库迁移

## 九、项目实践

学习全栈最重要的是做完整项目。建议从简单到复杂逐步练习：

- 个人博客系统
- 后台管理系统
- 登录注册与权限系统
- 在线笔记系统
- 文件上传与图片管理系统
- 电商商品与订单系统
- 即时聊天系统
- 数据可视化看板

每个项目都尽量完整包含：

- 需求分析
- 数据库设计
- 接口设计
- 前端页面开发
- 后端接口开发
- 登录鉴权
- 错误处理
- 测试
- 部署上线
- 文档整理

## 十、推荐学习顺序

如果从前端基础开始，可以按这个顺序推进：

1. HTML、CSS、JavaScript
2. TypeScript
3. Vue 或 React
4. Git 与 npm 工具链
5. Node.js 基础
6. Express / Koa / NestJS
7. MySQL 与 Redis
8. 接口设计与登录鉴权
9. Linux、Nginx、Docker
10. CI/CD 与项目部署
11. 安全、性能优化、系统设计
12. 完整项目复盘与面试整理

## 十一、面试重点

全栈岗位面试通常会重点关注：

- 前端基础是否扎实
- 是否理解框架原理
- 是否能独立设计接口
- 是否能设计合理的数据表
- 是否理解登录、鉴权、权限控制
- 是否熟悉项目部署流程
- 是否有完整项目经验
- 是否能定位线上问题
- 是否具备工程化和协作意识
- 是否理解常见安全与性能问题

## 十二、阶段目标

### 入门阶段

- 能完成静态页面
- 能使用 Vue 或 React 开发基础页面
- 能调用后端接口
- 能理解 Git、npm、打包工具的基本使用

### 进阶阶段

- 能独立开发一个前后端分离项目
- 能设计数据库表
- 能实现登录注册
- 能完成基础部署
- 能编写接口文档

### 熟练阶段

- 能处理权限、缓存、队列、日志、监控等问题
- 能优化前后端性能
- 能设计可维护的项目结构
- 能独立排查线上问题
- 能从业务角度设计技术方案

## 十三、总结

全栈工程师的核心能力不是记住所有技术名词，而是能把一个真实需求从想法变成稳定可用的系统。学习时不要只看教程，要多做项目、多写总结、多复盘问题，这样知识才会真正连起来。
