## HTML

### 语义化

- 常见语义化标签：`header`、`nav`、`main`、`section`、`article`、`aside`、`footer`
- 语义化的好处：结构清晰、利于 SEO、利于无障碍访问、便于维护
- `div` 和语义化标签的区别

### 表单

- 常见表单元素：`input`、`textarea`、`select`、`button`
- `input` 常见类型：`text`、`password`、`number`、`email`、`file`、`checkbox`、`radio`
- 表单校验：原生校验、自定义校验、提交前校验
- `label` 的作用：提升可访问性，扩大可点击区域

### SEO 与可访问性

- `title`、`meta description`、`meta keywords`
- 图片使用 `alt`
- 按钮和链接语义区分
- 合理使用标题层级：`h1` 到 `h6`

## 浏览器原理

### 页面渲染流程

- 解析 HTML，生成 DOM 树
- 解析 CSS，生成 CSSOM 树
- 合成 Render Tree
- Layout 布局
- Paint 绘制
- Composite 合成

### 回流与重绘

- 回流：元素尺寸、位置、结构变化
- 重绘：颜色、背景等视觉变化
- 回流一定会触发重绘，重绘不一定触发回流
- 优化方式：批量修改 DOM、使用 `transform`、减少强制同步布局

### 存储

- Cookie：容量小，可随请求发送
- localStorage：持久化存储，同源共享
- sessionStorage：页面会话级存储
- IndexedDB：大量结构化数据存储

### 事件机制

- 事件捕获、目标阶段、事件冒泡
- 事件委托
- `preventDefault`
- `stopPropagation`
- passive 事件监听
