## 安卓基础

### 安卓是什么

- Google 推出的移动操作系统
- 基于 Linux 内核
- 主要使用 Kotlin 和 Java 开发应用
- 应用运行在 Android Runtime 上

### 安卓系统架构

- Linux Kernel
- Hardware Abstraction Layer
- Android Runtime
- Native C/C++ Libraries
- Java API Framework
- System Apps

### 应用基础概念

- APK
- Activity
- Service
- BroadcastReceiver
- ContentProvider
- Intent
- Context
- Manifest
